1. Request enters Spring MVC
2. Spring tries to prepare controller method arguments
3. @Valid detects invalid data
4. Spring throws MethodArgumentNotValidException
5. Spring searches for a matching @ExceptionHandler
6. GlobalExceptionHandler handles it
7. A custom response is returned
